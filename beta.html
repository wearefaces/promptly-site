Requirements

  • macOS 26 or laterPromptly is a native Swift and SwiftUI app.
  • Apple siliconRequired to run Promptly.
  • Menu bar appLives in the menu bar. There is no Dock icon.
  • Accessibility accessNeeded to read the text you select and paste into desktop AI apps.

Install

Open the disk image and drag Promptly to Applications. Open it from Applications — it lives in the menu bar. Then grant Accessibility access, from Promptly's Settings or from System Settings → Privacy & Security → Accessibility.
